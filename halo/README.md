# حلقة فوق الراس (Halo)

| الملف | الوصف |
|---|---|
| `source.jpg` | الصورة الأصلية |
| `output.png` | الصورة مع الحلقة (بدون فقد جودة) |
| `output.jpg` | نفس النتيجة بحجم أخف للمشاركة |
| `add_halo.py` | السكربت اللي يرسم الحلقة |

## وش يسوي السكربت

- يرسم حلقة بيضاوية رفيعة ومسطّحة (مثل الصور المرجعية) تطفو فوق الراس، ومايلة مع ميلان الراس.
- لون الحلقة أبيض في النص وأطرافها لافندر بارد، مع فصل لوني خفيف بنفسجي وأزرق ثلجي على الحواف.
- الألوان مأخوذة من الصورة نفسها: الكحلي للظلال، واللافندر للدرجات الوسطى، والأبيض للإضاءة.
- التوهج والإطار الكحلي مطبوعين بنفس شبكة النقاط (halftone) اللي في الصورة، بنفس الزاوية والتردد والطور، فتطلع الحلقة كأنها جزء من الطباعة الأصلية.

## تعديل الحلقة

```bash
python3 add_halo.py source.jpg output.png \
  --cx 430 --cy 140 \   # مركز الحلقة
  --a 265 --b 52 \      # العرض والارتفاع (نص القطر)
  --tilt -14 \          # الميلان بالدرجات (سالب = الطرف اليمين أعلى)
  --width 9.5           # سماكة الخط
```

يحتاج بس `numpy` و `Pillow`.
