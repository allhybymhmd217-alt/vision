# حلقة فوق الراس (Halo)

## النسخة النهائية

| الملف | الوصف |
|---|---|
| `halo_final_2x.png` | **النهائية**: نفس صورتك ونفس الإطار، الحلقة أكبر 1.27 مرة ومايلة 5° أخف، مقاس 2508×2508 بدون أي فقد |
| `halo_final_2x.jpg` | نفسها JPEG بأعلى جودة (100)، الحجم 3.9 ميجا (أقل من 4) |
| `halo_final.png` | نفسها بمقاس صورتك الأصلي 1254×1254 |
| `edit.jpg` | صورتك اللي فيها الحلقة (الأساس) |

### وش صار (`enlarge_halo.py`)

- **بدون زوم آوت**: نفس الإطار ونفس المقاس.
- **الحلقة كبرت 1.27 مرة بنفس شكلها**، لأنها مكبّرة من بكسلات حلقتك نفسها. أضفت حدة خفيفة تعوّض النعومة اللي يجيبها التكبير، فتطلع حادة زي باقي الصورة.
- **الزاوية**: صارت أخف ميلان بـ 5°، يعني طرفها اليمين نزل شوي.
  - صارت متزنة أكثر فوق الراس.
  - هذا الاتجاه يخليها تكبر وهي داخل الإطار. لو ميلناها للجهة الثانية، طرفها اليمين يطلع برا الصورة من فوق.
- **مكانها**: الحلقة الجديدة تغطي القديمة كاملة. والقوس الأمامي باقي على الراس تقريباً بنفس المكان (نزل كم بكسل بس).
- **النجوم والوميض واللمعات**: كبرت ومالت مع الحلقة، ومكانها القديم تعبّى بالخلفية اللي تحته.
- **باقي الصورة**: كل شي بعيد عن الحلقة ببكسلات صورتك نفسها بالضبط (تأكدت منها بكسل بكسل).
- **الحافة اليمين**: كان فيها خط أخضر رفيع (آخر 3 أعمدة). أخذ لون العمود اللي جنبه، وسطوعه ما تغيّر.

## النسخ السابقة

نسخة الزوم آوت من صورتك موجودة في تاريخ git (commit `59a2d04`). وتقدر تبنيها من جديد بـ:
`enlarge_halo.py ... --scale 1.3 --rotate 0 --pivot 1 --margins 64 80 48 32`

## إعادة البناء

```bash
./make.sh
```

يحتاج `numpy` و `scipy` و `Pillow`.

## تعديل الحجم أو الزاوية

```bash
python3 enlarge_halo.py edit.jpg source.jpg halo_final.png --scale 1.27 --rotate 5
python3 upscale.py halo_final.png halo_final_2x.png --scale 2 --plain
```

- `--scale`: حجم الحلقة. فوق 1.28 تقريباً تبدأ تطلع من الإطار.
- `--rotate`: الزاوية بالدرجات. الموجب يخليها أخف ميلان.
